미션 ① 예제 해부

```
  Damp → 준비/기립 전이 → 기립(균형) → [ 상체 모션 (손 흔들기) ] → 복귀 → Damp
                                    └────────── 이상 시 언제든 Damp로 복귀 ──────────┘
```
- 전이 사이 대기(sleep)가 필요한 이유:
  로봇이 한 상태(예: 기립)를 물리적으로 완전히 완성할 시간을 주기 위함. 전이가 끝나지 않은 상태에서 다음 명령이 들어오면 명령이 겹쳐 이상 거동이 발생할 수 있음 (5.1절 "흔한 실수" 참조)
- Ctrl+C 중단 시 로봇이 남는 상태 / 안전 여부:
  예외 처리(try/except)가 Damp 호출로 끝나도록 작성돼 있다면 힘이 빠진 안전 상태로 복귀 — 단, 예외 처리가 없다면 중단 시점의 임의 자세로 남아 위험할 수 있음.
