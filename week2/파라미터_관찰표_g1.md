# G1 보행 파라미터 관찰표 (교재 4.3~4.4)

> 작성자: choidayeon · 작성일: 2026-08-05
> 원칙(교재 4.3): **한 번에 하나만** 바꾸고, 기록 후 **기본값으로 복원**한 뒤 다음 파라미터로.
> 실행: `python3 examples/01_walk_demo.py --params config/gait_params.yaml` (뷰어 관찰용)
> 사전 경계 확인(선택): `python3 param_sweep.py` (헤드리스, 참고용)

## 0. 기본값 (`config/gait_params.yaml`)

| 파라미터 | 기본값 | 단위 | 의미 |
|---|---|---|---|
| vx | 0.10 | m/s | 전진 속도 명령 (+앞 / −뒤) |
| vy | 0.0 | m/s | 횡이동 속도 (+왼쪽) |
| vyaw | 0.0 | rad/s | 회전 속도 (+반시계, 제자리 회전 권장) |
| step_period | 0.45 | s | 걸음 주기 (왼발+오른발 1사이클) |
| step_height | 0.04 | m | 스윙(유각) 발 들어올림 높이 |
| com_shift | 0.045 | m | 좌우 무게중심 이동 폭 |
| pelvis_height | 0.755 | m | 보행 중 골반 높이 |
| arm_swing | 0.12 | rad | 보행 팔 스윙 진폭 (0이면 팔 고정) |

## 1. 파라미터 스윕 관찰표

다음 표는 `param_sweep.py`의 기본 시도 목록을 뷰어 관찰용으로 옮긴 것입니다.
직접 값을 바꿔 실행하며 **결과 이후 열**을 채우세요. (한 시도 끝나면 값을 기본값으로 복원)

| # | 시도 | 바꾼 파라미터 = 값 | 명령(vx/vy/vyaw) | 결과(완주/낙상) | 낙상 시점(t, s) | 낙상 방향(앞/뒤/좌/우) | 실측 평균속도(m/s) | 관찰 메모 |
|---|---|---|---|---|---|---|---|---|
| 1 | 기본값 확인 | (없음, 기본값) | 0.10 / 0 / 0 | | | | | |
| 2 | 고속 경계 안쪽 | vx=0.45 | 0.45 / 0 / 0 | | | | | |
| 3 | 고속 경계(낙상 예상) | vx=0.50 | 0.50 / 0 / 0 | | | | | |
| 4 | 짧은 주기 | step_period=0.30 | 0.10 / 0 / 0 | | | | | |
| 5 | 긴 주기 | step_period=0.90 | 0.10 / 0 / 0 | | | | | |
| 6 | 낮은 스윙 높이 | step_height=0.02 | 0.10 / 0 / 0 | | | | | |
| 7 | 높은 스윙 높이 | step_height=0.07 | 0.10 / 0 / 0 | | | | | |
| 8 | 무게중심 이동 작게 | com_shift=0.02 | 0.10 / 0 / 0 | | | | | |
| 9 | 무게중심 이동 크게 | com_shift=0.08 | 0.10 / 0 / 0 | | | | | |
| 10 | 횡이동 | (없음) | 0 / 0.08 / 0 | | | | | |
| 11 | 제자리 회전 안정 | (없음) | 0 / 0 / 0.25 | | | | | |
| 12 | 제자리 회전 경계(낙상 예상) | (없음) | 0 / 0 / 0.50 | | | | | |
| 13 | (추가 자유 시도 1) | | | | | | | |
| 14 | (추가 자유 시도 2) | | | | | | | |

> 참고 경계(저장소 검증값, 버전에 따라 달라질 수 있음 — 다르게 나오면 그게 새 관측치): vx≈0.5 낙상 / vyaw 0.25 완주·0.5 낙상.
> 실측 속도가 명령값(vx)보다 작게 나오는 것은 정상입니다 — 왜 다른지 메모에 남겨보세요.
