새로운 터미널을 하나 더 열고 다음 명령을 실행합니다.
```
cd ~/Desktop/unitree_ros2

source /opt/ros/humble/setup.bash
source setup.sh
source install/setup.bash

ros2 run teleop_twist_keyboard teleop_twist_keyboard \
--ros-args -p speed:=0.5 -p turn:=1.0
```
화면에 표시되는 키를 이용해 다음 동작으르 확인합니다.
```
전진
후진
좌우 이동
회전
```
정지
```
k
```
프로그램 종료
```
Ctrl + C
```
로봇이 예상하지 못한 방향으로 움직일 경우 즉시 k를 누르거나 리모컨을 이용해 정지합니다.
