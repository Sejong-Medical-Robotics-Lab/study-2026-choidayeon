## SpoerClient 생성
```
SportClient sport_client_;
unitree_api::msg::Request req_;
```
SportClient를 이용하여 Unitree Sport API 명령을 전달합니다.

## 기립 명령
```
sport_client_.StandUp(req_);
```
실행되면 Go2에 기립 명령을 전달합니다.
## 자세 낮추기 명령
```
sport_client_.StandDown(req_);
```
Go2에 자세를 낮추는 명령을 전달합니다.
## 정지 명령
``` 
sport_client_.StopMove(req_);
```
현재 이동 명령을 정지합니다.

프로그램을 종료할 때도 명시적으로 StopMove()를 호출합니다.
