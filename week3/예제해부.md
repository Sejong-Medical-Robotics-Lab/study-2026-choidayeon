- 플래닝 그룹 이름과 속한 관절들: _(예제 코드 확인 — 통상 "arm" 그룹, J1~J7)_
- plan 실패 시 스크립트 동작 / execute를 그냥 부르면 위험한 이유:
  성공 여부를 확인하지 않고 execute를 호출하면 실패한(또는 계산되지 않은) 궤적을 실행하려 시도하게 되어 무동작 또는 의도치 않은 동작(이전 계획 재실행 등)이 발생할 수 있음. 따라서 `if plan 성공: execute()` 구조가 필수 (5.1절)
- orientation 표현 형식 / 새로 계산하는지 재사용하는지:
  쿼터니언(x,y,z,w)으로 표현. 이번 주 실습에서는 "그리퍼가 수직으로 아래를 보는 자세" 상수를 재사용하는 것이 일반적 (5.2절)
