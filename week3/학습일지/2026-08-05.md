# 학습일지 — 2026-08-05 (Week 3)

## 오늘 배운 것
- RM 로봇팔의 URDF/모델 구조에 EG2-4C2 그리퍼를 엔드이펙터로 결합하는 방법. 팔 링크와 그리퍼 베이스를 조인트로 연결해 하나의 완성된 매니퓰레이터 모델로 만드는 과정을 이해함
- 결합한 모델을 Gazebo 시뮬레이션에 올려 실제 물리 환경(중력, 충돌)에서 팔과 그리퍼가 어떻게 동작하는지 확인
- MoveIt 기반 워크플로우: 목표 지정(Set Goal) → 경로 계획(Plan) → 실행(Execute)이 분리된 3단계로 이루어진다는 것, 그리고 Plan 단계에서 충돌 검사와 IK(역기구학) 계산이 먼저 수행된 뒤에야 Execute가 가능하다는 원리

## 직접 해본 것 / 성공한 것
- RViz에서 엔드이펙터에 붙은 주황색 인터랙티브 마커를 손으로 끌어서 원하는 위치·자세로 목표 pose를 지정
- 지정한 목표에 대해 Plan을 실행 → 초록색 경로(trajectory)가 그려지는 것을 확인하고, 충돌 없이 도달 가능한 계획이 나올 때까지 목표 위치를 조금씩 조정해봄
- 계획이 성공적으로 나온 것을 Execute로 실행해 Gazebo 상에서 실제 팔과 그리퍼가 해당 자세로 움직이는 것까지 확인

## 막힌 것 / 이해가 안 되는 것 (다음 Q&A 때 질문할 목록)
- 그리퍼 자체의 open/close 제어를 Plan/Execute와 별도의 액션으로 다뤄야 하는지, 아니면 팔의 모션 계획 안에 포함시킬 수 있는지 궁금함

## 한 줄 소감
