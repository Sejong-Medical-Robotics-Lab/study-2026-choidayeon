## 오늘 배운 것
- 팔(`rm_description`)과 그리퍼(`gripper_description`)가 원래 별개의 URDF/Xacro 패키지로 분리되어 있고, 이 둘을 하나의 로봇으로 합치려면 `fixed` 타입의 연결 조인트 하나만 새로 정의하면 된다는 것
- 연결 조인트(`arm_jaw_joint`)의 `origin`에는 실측으로 얻은 보정값(z=-0.009, rpy z=-1.57)이 들어가야 팔 끝(`Link7`)과 그리퍼 베이스(`4C2_baselink`)가 어긋나지 않고 딱 맞물린다는 것
- 파지 기준점(`grasp_tcp`)처럼 물리적 링크가 아닌 "가상의 기준 좌표"도 링크+조인트로 선언해서 TF 트리에 넣을 수 있다는 것
- RViz의 `joint_state_publisher_gui`는 Gazebo 없이도 각 관절 각도를 슬라이더로 직접 넣어보며 URDF 결합이 올바른지(관절 개수, 그리퍼 개폐, TF 정렬) 눈으로 검증하는 용도로 쓰인다는 것
